작은 마을을 초대하세요.

주소를 넣고 코드를 복사한 뒤, 스킨에 한 번 붙여 넣으면 됩니다.

티스토리 기본 주소나 연결한 개인 도메인을 입력해 주세요.

코드를 복사하세요.

내 블로그 스킨에 붙여 넣으세요.

관리자에서 꾸미기 → 스킨 편집 → HTML 편집을 열고, 마을을 넣을 위치에 코드를 붙여 넣어 저장하세요.

내 블로그 관리자 열기

주소 입력만으로 설치되지는 않습니다. 최초 한 번은 블로그 소유자가 코드를 붙여 넣어야 해요. 이후 페이지를 열면 오늘 방문자 수를 사용합니다.
