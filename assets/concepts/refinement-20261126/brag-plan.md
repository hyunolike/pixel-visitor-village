# 작은 방문자 마을 — 현재 서비스 소개 영상

20초,1920×1080,30fps. 기존 실제 위젯 시연과 음악을 유지하며 현재 UI와 글꼴에 맞춘다. 대상은 티스토리 블로그에 작은 방문자 마을을 설치하려는 사람이다. 첫 문구에서 오늘 방문자 수를 캐릭터로 보여주는 위젯임을 설명한다.

| 시간 | 실제 장면 | 읽을 문구와 동작 |
| --- | --- | --- |
| 0–3.4초 | 크리스마스 마을의0→24 시연 | 티스토리 오늘 방문 수. 숫자와 함께 캐릭터가 모임 |
| 3.4–6.8초 | 실제 두 캐릭터의 인사 | 가까이 마주치면 손 인사와 말풍선 |
| 6.8–8.83초 | 실제 크리스마스 손님 | 산타나 루돌프가 들르는 계절 장식 |
| 8.83–13.33초 | 봄,여름,가을,겨울 실제 풍경 | 계절을 고르면 풍경이 바뀜. 앞 장면의 크리스마스와 함께 다섯 계절 |
| 13.33–17초 | 현재 설치 화면에서 여름 선택→주소 없이 코드 생성 | 계절 선택,코드 복사,스킨에 붙여넣기 |
| 17–20초 | 현재 나무 로고와 마을 | Neo둥근모 제목과 실제 서비스 URL.24명은 시연용임을 표시 |

프레임585의 안정된 마무리를 포스터와 영상 첫 프레임으로 사용한다. 프레임을 추가하지 않고 첫 프레임만 바꿔20초와 음원 동기를 유지한다. 중간 프레임과 전환을 스틸로 검사한 뒤 전체 렌더를 실행한다. 실제 사람 정보, 가상의 추천사나 설치 완료 주장은 넣지 않는다.

음원은 기존 소개 영상의 AAC 스트림을 그대로 재사용한다. 원곡은 Sascha Ende의 Happy Beats(Business Moves Vol.10),CC BY4.0이며 기존 효과음과20초 편집을 포함한다. 새 유료 서비스나 새 음성 합성은 사용하지 않는다.
