# 첨부 콘셉트 기반 마을 원화

## 2026-11-26 런타임 픽셀 마감

원래1254px 생성 원화는 아래 이력과 함께 그대로 보존한다. 현재 실행 PNG는 사용자가 명시적으로 허용한 Python/Pillow 방식으로 마감했다. [마감 입력 스냅샷과 기록](refinement-20261126/provenance.json)은 이전 배포 커밋의180px 실행 파일을 기준으로 한다. `python3 scripts/media/refine-pixel-assets.py prepare`, `finish`, `check` 순서로 재현한다. Pillow가 필요하며 실제 사용 버전은 기록에 있다.

공유 숲색과 나무색, 크림색 명암에 계절별 색을 배정하고 과일과 리본 같은 작은 강조색을 보존했다. 색상은 나무별32색 이하, 조형물16색 이하이며 디더링 없이 가장 가까운 색을 사용한다. 기존180px 격자에서 작은 색상 잡음을 정리하고 알파를0/255로 맞췄다. 공간 리샘플링 없이 원본의 알파128 이상 외곽 마스크가 일치하는지 검사한다. 생성 도구의 첫 수정안은 그라데이션이 남아 채택하지 않았다.

이전 실행 입력과 마감 결과의 크기, 팔레트, 알파, 바이트 수와 해시는 [exports.json](refinement-20261126/exports.json), 전체 비교는 [마감 전후](../../../docs/assets/refinement/art-seasons.png)에서 확인한다. 원화 전체를 새로 그렸거나 모든 세부 색이 동일하다고 설명하지 않는다. 출처와 티스토리 브랜드에 대한 아래 설명은 계속 적용한다.

## 최초 원화와 변환 이력

사용자가 제공한 [콘셉트 이미지](../../../docs/assets/cozy-village-reference.jpg)를 기준으로 2026-11-25 내장 image_gen으로 나무5종과 티스토리 조형물을 제작했다. 외부 게임 에셋을 가져오지 않았다. 첨부 이미지는 아트 디렉션 참고이며 실제 서비스 캡처와 구분한다.

| 원본 | 내용 |
| --- | --- |
| tree-summer.png | 둥근 수관,자연스럽게 갈라지는 줄기와 붉은 과일 |
| tree-spring.png | 같은 여름 나무 구조를 유지한 분홍 꽃나무 |
| tree-autumn.png | 비대칭 가지와 주황/황금색 잎 묶음 |
| tree-winter.png | 가늘어지는 가지에 크림색 눈을 얹은 겨울나무 |
| tree-christmas.png | 굵은 잎 묶음,별/리본/금색 장식/선물의 크리스마스 나무 |
| tistory-monument.png | 빨간 원 안에 크림색 다섯 점(3+1+1),돌 받침대의 독립 장식 |

이 폴더는 생성 원본을 수정 없이 보관한다. 나무 원본은1254×1254,조형물도1254×1254 RGBA다. 요청한 정확한 도트 격자/1024px 출력과 실제 생성 결과는 차이가 있으며 미세한 그라데이션과 저알파 가장자리가 있다. 실제 크기에서 검수해 채택했다. 티스토리 표장은 해당 서비스의 브랜드이며 자체 브랜드나 공식 제휴 표시로 설명하지 않는다.

실행용 [src/assets/cozy](../../../src/assets/cozy/)는 브라우저 Canvas에서 원본 전체를180×180로 nearest 렌더한 PNG다. 배경 합성/수동 재페인팅/장식 삭제 없이 투명도를 유지한 기술적 크기 변환이다.6개 합계208,003bytes이며 파일별 해시는 [exports.json](exports.json)에 있다. 독립 모듈은 실행 PNG를 포함하므로 추가 외부 이미지 경로에 의존하지 않는다.

전체 프롬프트와 생성 파일 식별자는 [prompts.json](prompts.json)에 있다. 기본 지시는 첨부의 청록 윤곽/따뜻한 녹색/크림/테라코타,큰 픽셀 묶음,윗왼쪽 빛,단순 명암,완전 투명 배경,독립된 전체 오브젝트와 여백이었다. 봄은 생성한 여름 나무도 참고해 동일 구조를 유지했다. 정상 아트를 읽지 못할 때만 src/art.ts의 직접 그린 대체 나무/조형물을 표시한다.

캐릭터8종/3방향/8프레임,소품7종과 배경/산타/루돌프/말풍선은 기존 편집 가능한 RGBA/Canvas 원본을 직접 수정했다. 새 PNG로 모든 프레임을 생성했다고 설명하지 않는다. 완성된 정적 포스터에 방문자를 굽지 않고 실제 인원/이동/계절/깊이 정렬을 유지한다.
