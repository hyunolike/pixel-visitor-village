# 작은 방문자 마을 — 20초 소개 영상 리메이크 기획

## 실행 기록

- 호출: Claude Code `Skill` 도구로 `brag:brag`를 실제 호출했다. 인자는 `--tone polished --duration 20 --format landscape`이다.
- 모델 분기: 스킬의 첫 단계 규칙("Opus 5.5·Sonnet 5.5·Fable 5.2이고 `--full`/`--voice`가 없으면 brag-slim으로 전환")에 따라 실행 모델 **Claude Opus 5.5 (`claude-opus-5-5`)**는 번들 `slim.md`(/brag-slim) 절차로 진행했다. 그래서 Hyperframes CLI 대신 이미 설치된 도구(Vite, Playwright + Google Chrome, ffmpeg)로 직접 합성했다.
- 내레이션은 없다(`--voice` 미사용). 중간 선택 질문 없이 끝까지 진행했다.
- 작업 위치는 `brag-output/claude-brag-remake-20261125/`(Git 제외 경로)이다. 중간 산출물은 모두 `work/` 안에 있다. 이전 `brag-output/intro-refresh/`는 읽기만 했다. README 썸네일과 `src/`, `public/`, 설정 파일은 건드리지 않았다.

## 한 문장

티스토리의 오늘 누적 방문 수만큼 픽셀 캐릭터가 모이고, 서로 인사하고, 계절이 바뀌는 블로그 위젯이다.

## 기획 질문 답

| 질문 | 답 |
|---|---|
| 무엇인가 | 티스토리 오늘 방문 수를 픽셀 캐릭터 마을로 보여 주는 PixiJS 웹 컴포넌트 `<visitor-village>` |
| 누구를 위한가 | 블로그에 따뜻한 방문 표시를 두고 싶은 티스토리 운영자 |
| 차별점 | 숫자가 그대로 캐릭터 수가 된다. 가까운 캐릭터끼리 손 인사와 말풍선을 주고받고, 크리스마스에는 산타나 루돌프가 들른다 |
| 가장 인상적인 주장 | 방문이 한 명 늘면 마을에 한 명이 늘어난다 |
| 시각 훅 | 빈 크리스마스 광장에 0→24로 숫자가 오르며 캐릭터가 하나씩 나타난다 |
| 실제 UI | 실제 위젯(소스 직접 실행), 실제 설치 작업실 촬영본 |
| 톤 | polished: 차분하고 정돈된 카피, 긴 홀드, 부드러운 전환 |
| 공유 문구 | 아래 `share-copy.txt` |

## 정직성·개인정보 원칙

- 24명은 **시연용 숫자**다. 훅 장면의 카운터 옆 작은 `시연` 배지와 마지막 장면 한 줄로만 짧게 표시한다. 동시 접속자나 개별 방문자로 설명하지 않는다.
- 캐릭터는 실제 방문자와 연결되지 않는다. 화면 속 데이터는 모두 시연 값이고 설치 화면 주소는 `example.tistory.com`이다.
- 티스토리 원·돌 받침은 제품 현재 상태인 작은 우물 크기 그대로다. 큰 로고로 되돌리지 않는다. 참고 이미지 `work/user-reference.jpg`의 큰 로고와 긴 하단 문구는 복제하지 않는다.

## 소재 — 실제 제품만 사용

1. **실제 위젯 캡처**(`work/capture/index.html`, `work/scripts/capture.mjs`): 저장소 Vite 개발 서버(포트 5291, 이 작업 전용)로 `/src/visitor-village.ts`를 그대로 import한다. 위젯을 `paused`로 두고 매 프레임 제품 코드의 `model.step(1/30)`, `cameo.step(1/30)`, `renderOnce()`를 호출해 1280×720 PNG로 찍는다. 캐릭터, 말풍선, 나무, 우물 크기의 티스토리 기념물, 계절 소품, 눈·꽃잎, 방문 팻말이 모두 제품 렌더러의 결과다.
   - 결정성을 위해 `Math.random`을 시드 고정(mulberry32)했다. 위젯의 3초 팻말 타이머와 Shadow DOM CSS 전환은 영상 시간에 맞춰 진행시켰다.
   - 연출로 개입한 것은 두 가지뿐이다. 방문 수 속성을 0→24로 올렸고(설치 후 숫자가 바뀌는 것과 같은 경로), 루돌프·산타 카메오의 대기 시간을 0으로 만들어 등장 시점을 정했다. 산타와 루돌프 중 누가 오는지와 위치는 제품의 시드 난수가 정했고, 이번 테이크에서는 루돌프가 나왔다.
2. **설치 작업실 촬영본** `brag-output/intro-refresh/assets/installer-current.mp4`(실제 install 페이지, 4초)의 프레임 19–100(0.63–3.37초) 구간을 1배속으로 썼다.
3. 글꼴: NanumSquareRound R/B(로컬 파일). 색: 제품의 `themes.ts`·`design-system.css` 값(크리스마스 하늘 `#10383c`, 액션 `#1c5d56`/`#a4d7c9`, 크림 `#f0dba8`/`#fff4ce`). 브랜드 표식은 제품 CSS의 `.brand-mark` 클립 패스를 그대로 썼다.

## 검토 중 고친 것 (스틸 기준)

모든 장면의 정착 스틸과 전환 경계 스틸(각 요소의 퇴장 끝과 다음 요소의 등장 시작 프레임: 86, 91, 98, 109, 201, 206, 210, 266, 306, 347, 388, 426, 430, 505, 508, 512, 517)을 직접 봤다. 스틸과 타일은 `work/stills/`, `work/sheet-*.png`에 있다.

1. 훅: 두 번째 줄 제목이 지평선 아래 밝은 땅과 트리에 걸려 대비가 낮고 충돌했다. 문구를 줄이고 크기를 낮춰 왼쪽 밤하늘 안에 넣었으며 훅 장면의 줌을 없앴다.
2. 클로즈업: 아래쪽 빈 땅이 넓어서 줌을 3.0에서 3.6~3.9로 키웠다.
3. 계절: 제목이 나무 수관과 겹쳤고 줌 때문에 위젯의 계절 라벨이 잘렸다. 줌을 없애고 제목을 줄였다.
4. 설치: 캡션 카드가 코드 블록을 가렸고, 오른쪽 크롭에서 페이지 제목이 "…하나."로 잘렸다. 좌우 분할 레이아웃으로 바꿨다. 시작은 페이지 카드 전체(여백은 촬영본 배경색 `#f2f7f8`)이고, 끝 줌을 1.28로 낮춰 코드 블록이 잘리지 않게 했다.
5. 마무리: 브랜드 문구가 트리와 겹쳤다. 1.5배 왼쪽 위 기준 프레이밍으로 바꿔 넓어진 밤하늘에 배치했다.
6. 계절 와이프의 끝점이 아니라 중간점이 박에 오도록 옮겼다.

## 재생성 방법

1. 저장소 루트에서 `pnpm exec vite --port 5291 --strictPort --host 127.0.0.1`을 실행한다.
2. `node work/scripts/capture.mjs <christmas|spring|summer|autumn|winter|outro>`를 실행한다(`--dry`는 로그만 남긴다).
3. 설치 촬영본 프레임은 `ffmpeg -i …/installer-current.mp4 -start_number 0 work/frames/installer/%04d.png`로 뽑는다.
4. `node work/scripts/render.mjs full`로 `work/video-only.mp4`를 만든다. 확인용 스틸은 `render.mjs stills 0,50,…`로 뽑는다.
5. 오디오 믹스(`work/audio/mix.wav`)와 프레임 0 교체 인코딩은 위 오디오 설명대로 ffmpeg로 한다.

합계: 3.40 + 3.40 + 2.04 + 5.44 + 2.72 + 3.00 = 20.00초.

## 시각 원칙

- 화면을 가득 채운 실제 마을, 글자는 정사각 모서리의 진한 청록 카드(제품 디자인 시스템의 반경 0) 위에 둔다.

- 확대는 nearest-neighbor(pixelated)로 해서 픽셀 아트를 선명하게 유지한다.
