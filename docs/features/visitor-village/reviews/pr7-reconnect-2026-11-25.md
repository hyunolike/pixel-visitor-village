# PR #7 자정 이후 재연결된 집계 날짜

[자동 리뷰 P2](https://github.com/hyunolike/pixel-visitor-village/pull/7#discussion_r4690305634)를 실제 코드와 Chrome에서 확인했다. 연결 시 무조건 queueNotice를 호출해, 한국 자정 이후 재연결할 때 보존한 어제의 팻말/집계를 오늘 날짜로 덮어쓰는 문제였다.

수정은 count 입력 시점과 화면 연결 시점을 구분한다. 분리 중에도 유효한 count 입력의 스냅샷을 준비하고, 연결 시에는 기존 스냅샷/보류 팻말이 없는 최초 경우에만 기본 집계를 준비한다. 재연결 자체가 새 조회를 뜻하지 않는다.

VV-NOTICE-RECONNECT-001의 실제 Chrome 회귀 세 가지를 먼저 추가했다. 수정 전에는 보류한 팻말의 날짜와 이미 끝난 팻말의 새 재생 여부가 실패했고, 분리 중 새 count 입력은 통과했다(실패2/통과1). 원래 DOM 부모를 유지한 재현에서도 같은 실패를 확인했다.

수정 후 관련 팻말/초기 입력/설치 번역 검사10/10과 단위146/146,타입 검사와 앱/독립 모듈 빌드를 통과했다. 최종 전체 Chrome 브라우저 검사79/79(39.9초)와 git diff --check도 통과했다. 신규 테스트는 자정 재연결,이미 끝난 팻말,분리 중 새 입력을 구분하며 같은 숫자를 재입력한 오늘의 집계도 확인한다.

이 수정은 날짜가 바뀐 재연결의 팻말 처리다. 기존 소개 영상의 촬영 모듈 해시는 촬영 당시의 기록으로 보존하며, 이 후속 수정의 모듈 바이트와 같다고 주장하지 않는다.
