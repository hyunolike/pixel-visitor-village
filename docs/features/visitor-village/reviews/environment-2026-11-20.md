# 마을 환경 개선 독립 코드 검토

검토일: 2026-11-20. 기준 커밋: `fd23ff6`. 검토 브랜치: `feat/village-environment-art`의 미커밋 작업 트리. 별도 문맥의 읽기 전용 검토자가 코드와 PixiJS 8.23의 자원 해제 구현을 확인했다.

## 범위

`src/art.ts`, `src/pixel-art.ts`, `src/environment.ts`, `src/environment-layout.ts`, `src/environment-layout.test.ts`, `src/renderer.ts` 전체와 VV-013~015, 환경 설계와 실행 계획. 실제 환경 확대 시트와 봄/크리스마스/모바일 캡처도 확인했다.

## 결과

확정된 중요 문제는 보고되지 않았다.

- 소품 Sprite 제거 후 프레임 Texture는 공유 소스 없이 해제하며, 마지막에 아틀라스 소스를 한 번 해제한다.
- 테마 변경, 크기 변경과 파괴, 초기화 취소 경로가 기존 캐릭터 Texture를 파괴하지 않는다.
- 매 프레임 환경 에셋을 다시 생성하지 않는다. 고정 소품과 캐릭터는 발 y를 기준으로 깊이를 정렬한다.
- 아주 작은 크기에서 양수 Canvas와 소품 범위, 기존 `backdrop/hash/surface` 계약을 유지한다.

검토자는 파일 수정과 테스트 실행을 하지 않았다. 단위/빌드/브라우저 검사와 5개 테마 전체의 최종 시각 확인은 구현자의 별도 실행 결과다. 이 기록은 전체 EGM 반복 검토나 실제 티스토리 설치 검증 완료를 뜻하지 않는다. 새 건물 장애물과 상호작용은 이번 범위 밖이며 기존 이동 모델은 유지한다.
