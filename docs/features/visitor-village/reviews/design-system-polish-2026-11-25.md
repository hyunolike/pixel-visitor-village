## 실제 검토와 조치

- 독립 EGM 구현 준비 검토에서 작업 간 파일 의존성과 고급 설정을 닫을 때의 경고 노출을 Major로 지적했다. Task 1의 파일 경계에 상태/번역 파일을 포함하고 경고를 details 밖으로 옮겼다. 문서 경로 표기 Nit도 반영했다. 전체 5단계 EGM 검토를 완료한 것으로 기록하지 않는다.
- 기존 빌드에서 모바일 어절 분리, dirty 안내 부재, 전체 미리보기 링크와 hidden notice 접근성의 브라우저 실패 4건을 재현했다.
- 모바일 생성 버튼이 주소 blur 때 이동하여 click 대상이 form이 되는 현상을 pointer/focus 이벤트 로그로 확인했다. 주소에서 생성 버튼으로 초점이 옮겨가는 동안 정적 배치를 유지했다. 이어서 주소→고급 설정에서도 동일한 클릭 누락을 재현해 포인터 클릭이 끝날 때까지 모든 포커스 기반 배치 변경을 보류하고 다음 프레임에 동기화했다. 네 언어 오류 복구/코드 생성과 키보드 흐름으로 검증했다.
- 520px 경계에서 두 화면의 모바일 브랜드 크기가 갈라지는 실패를 재현했다. 공통 600px 규칙으로 통합했다.
- 새 문맥의 최종 독립 코드 검토는 Critical/Important 없음, 최신 포인터 수정의 브라우저 확인을 조건으로 통과했다. Minor 두 건은 동일 dirty 안내의 반복 DOM 갱신과 꺼진 옵션의 숨긴 경고 참조였다. 동일 안내는 내용이 바뀔 때만 갱신하고, 경고의 접근성 설명 연결은 켠 동안에만 유지하도록 수정했다. 숨긴 경고가 꺼진 체크박스의 설명에 포함되는 실패를 먼저 확인했다. 리뷰어는 최신 포인터/제어 변경을 브라우저로 재검증하지 않았으며 구현 담당자의 실제 빌드 검사로 보완한다.
