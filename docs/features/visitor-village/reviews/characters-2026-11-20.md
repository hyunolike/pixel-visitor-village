# 캐릭터 개선 독립 코드 검토

검토일: 2026-11-20. 기준 커밋: `05c0592`. 검토 브랜치: `feat/pixel-character-art`의 미커밋 작업 트리. 별도 문맥의 읽기 전용 검토자가 실제 코드와 PixiJS 내부 구현을 확인했다.

## 범위

`src/art.ts`, `src/renderer.ts`, 신규 `src/characters.ts`, `src/character-motion.ts`와 두 단위 테스트 파일, 관련 명세/설계/계획 변경. 외형 미리보기는 구현자가 별도로 재촬영해 확인했다.

## 결과

확정된 중요 결함은 보고되지 않았다.

- Sprite 제거와 프레임 Texture 해제는 공유 TextureSource를 파괴하지 않는다. 마지막에 아틀라스 Texture에서 소스를 한 번 해제하는 경로를 PixiJS 코드에서 확인했다.
- 위젯마다 별도 Canvas가 사용되어 캐시 충돌이 없고 빠른 재연결 취소 경로와 계절 변경에서도 공유 소스가 섞이지 않는다.
- 방문자별 매 프레임 픽셀 생성과 아틀라스 업로드가 없고, 동작 선택 결과 객체도 재사용한다.
- 화면상 속도로 방향을 선택하며 모델의 걷기 조건과 elapsed를 사용한다.
- 구현 중 발견한 모자 상단 잘림과 안경 캐릭터의 깜박임 가림을 실패하는 회귀 검사로 재현하고 수정했다. 검토자가 수정과 테스트를 확인했다.

검토자는 테스트를 실행하지 않았다. 단위 테스트와 브라우저 실행 결과는 구현자의 검증 기록이며, 전체 EGM 반복 검토 완료나 실제 티스토리 설치 검증을 뜻하지 않는다.
