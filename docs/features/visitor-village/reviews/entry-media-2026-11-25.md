# 이미지 버튼과 소개 미디어 최종 갱신

사용자가 마을 구경하기를 클릭 가능한 이미지 버튼으로 만들고 README/영상/홈의 전체 갱신을 요청했다. [계획](../entry-media-plan.md)을 따른다.

## 구현과 검증

- 네 README의 이미지 버튼은 홈/#demo로 연결된다. 현재 여름 나무와 캐릭터 RGBA로 SVG를 직접 만들었다. 레이블56px,640px 표시에서35.8px이며375px 화면의327px 이미지에서약18.3px다. 보조 문구는 작지만 주요 행동의 의미는 링크 이미지 대체 텍스트와 큰 제목으로 전달한다. 외부 리소스/스크립트를 포함하지 않는다.
- 후속 사용자 요청으로 상단1734×907px 소개 썸네일은 기존 readme-tistory-village.png를 유지한다. 축소 편집 시안은 채택하지 않았다. 네 README의 이미지 참조를 되돌렸으며 기존 파일이 Git 기준과 바이트 단위로 같음을 확인했다. 이미지 버튼/소개 영상/배포 결과는 유지한다.
- 실제production PixiJS 위젯과 설치 작업실을 재촬영해 MP4/GIF/포스터 및 구조도 화면을 갱신했다.20초/1920×1080/30fps/600프레임/H.264/AAC,기존음원/효과음/출처를 유지했다. 촬영모듈SHA와현재빌드SHA f3a5147f…가 일치한다. 파일별SHA와규격은 [근거](entry-media-evidence.json)에 있다.
- 단위146/146,타입/앱/독립모듈빌드,전체Chrome79/79(42.5초),README4개상대링크/이미지와diff검사통과.4개이미지가모바일327px 안에 표시되고클릭시실제마을준비완료/#demo로이동했다. pageerror0.
- HyperFrames lint/runtime/layout/motion/contrast/craft/audio모두오류0/경고0. 샌드박스에서로컬미디어CORS/캐시쓰기오류가있었고허용된실제환경에서다시실행해통과했다.5210편집미리보기를열고5장장면표와디코딩한10.5초를직접확인했다. 새내레이션이나유료미디어는없다.

## 독립 검토

별도문맥 entry_media_review가 코드/네SVG/원화/연결/메타데이터를 검토했다. 치명0,중요1(EN/JA/ZH의과거로컬준비본문구잔류),경미1(보조문구크기). 중요문구를한국어와같은실제작은조형물설명으로맞췄다. 보조문구는행동의필수정보가아니고큰제목/대체텍스트로의미를전달하므로현재구성을유지했다. 검토자는GitHub실제렌더링/공개배포/티스토리스킨을확인하지않았으며구현담당의공개검증은아래별도기록한다. 전체EGM다단계심사를수행했다는의미는아니다.

## 배포 준비

기존Cloudflare계정96dc7e6d07c8cb414af597acfec30146과Pages pixel-visitor-village,production/main을확인했다. 직전production1a1111e3이다. 고정묶음 /private/tmp/pvv-entry-release/dist는35개파일/6,837,943bytes이며 소스입력과파일별SHA를manifest에보존했다. 실제제품코드/설치계약은변경하지않았고새미디어와이미지버튼을포함한다. README변경은현재작업공간에있으며새커밋/푸시는이번요청에서수행하지않는다. 공개배포결과는검증후추가한다.


## 공개 반영과 확인

사용자의 전체 진행 요청 범위에서 기존 Pages production에 고정 빌드를 Direct Upload했다. 배포 ID는 `0f6d4807-05dc-40ac-b0da-4e8cb9d611bf`,고유 주소는 https://0f6d4807.pixel-visitor-village.pages.dev/ 이며 기존 공개 별칭에도 반영됐다. GitHub main 자동 배포는 구성하지 않았다. 대시보드의 소스 e9db2c5는 기준 커밋이며 이번 미디어 편집본은 미커밋 작업 공간에서 검증한 고정 묶음이다.

공개 검증7개 범주를 통과했다. _headers를 제외한34개 파일의SHA가 로컬 묶음과 일치한다. 위젯의 JS MIME/CORS/nosniff와 없는 파일404,다섯 계절의24명/작은 조형물 비율,새 영상 디코딩/시간 진행,320px 네 언어의 생성 코드/실제 클립보드/가로 넘침 없음,공개 이미지 버튼4개의 실제 체험 이동,별도HTTP출처37명 렌더링을 확인했다. pageerror는0건이다. 실제 공개 데스크톱/모바일 캡처는 docs/assets/entry/public-home-*.png에 있다.

초기 버튼 검증은 같은 홈URL에서 setContent로 문서를 대체해 hash 이동만 발생하는 잘못된 fixture였다. 독립된 about:blank 문서에 이미지 링크를 놓고 실제 전체 이동을 확인하도록 고쳐 전체 공개 검사를 다시 통과했다. 제품 코드를 바꾼 것이 아니다.

현재 홈/설치/소개 영상과 버튼 이미지는 공개 반영 완료이며 README4개와 출처/검수 문서는 작업 공간에 수정되어 있다. 새 커밋/푸시/PR은 이번 단계에서 수행하지 않았다. 실제 티스토리 스킨/실기기/보조기기는 확인하지 않았다. 편집 자료는 기존 HyperFrames 미리보기 http://localhost:5210/#project/intro-refresh 에서 계속 볼 수 있고 [HyperFrames desktop app](https://hyperframes.studio/studio/download?src=cli)에서도 편집할 수 있다.


## 풀리퀘스트와 커밋 기준 배포

사용자가 후속으로 “풀리퀘, 배포”를 요청했다. 기존 상단 썸네일 원본은 그대로 유지하며 네 README의 이미지 버튼과 최신 소개 미디어,검수/출처 기록을 커밋해 main 대상 PR로 전달한다. 검증한 같은 정적 파일을 커밋 기준으로 기존 Pages에 다시 배포한다. 위의 미커밋 배포 기록은 첫 반영 단계의 이력이다. PR 병합이나 자동 배포 설정은 이번 단계에서 수행하지 않는다.
