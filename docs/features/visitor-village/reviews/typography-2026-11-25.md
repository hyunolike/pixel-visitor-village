# 서비스 타이포그래피 적용 검증

## 범위와 결과

사용자의 폰트 변경 요청에 따라 기존 사이트 화면에만 적용했다. Neo둥근모 v1.600은 한국어/영어 브랜드16px, 큰 제목32/48px, 시연 수32px에 사용한다. 본문/섹션 제목/버튼/입력은 Pretendard Variable v1.3.9다. 일본어/중국어는 기존 언어용 시스템 스택을 사용한다. 레이아웃3안은 미선택이며 공개 배포/커밋/푸시는 수행하지 않았다.

픽셀 글꼴은 regular/자간0/16px 배수로 조판한다. 본문은 가변 굵기를 제공한다. 원본 WOFF2와 OFL 전문을 자체 제공하며 font-display:swap과 대체 글꼴을 사용한다. 다운로드 실패를 이유로 설치 흐름을 막지 않는다.

## 실제 검증

- `pnpm build`: 타입 검사, 사이트와 독립 위젯 빌드 통과.
- 최종 `pnpm test:e2e --output=/private/tmp/pvv-typography-green`: **79/79, 47.0초** 통과. 로직/모델 변경이 없어 단위 테스트는 이번에 다시 실행하지 않았다.
- 실제 Chrome 플랫폼 글꼴 검사: 홈 제목 NeoDunggeunmo-Regular, 본문 PretendardVariable-Regular가 custom font로 사용됨을 확인했다. CSS 선언만으로 판단하지 않았다.
- 네 언어 ×320/375/720/1440px에서 화면 넘침 없이 코드 생성. 일본어/중국어 제목에 Neo둥근모/Pretendard 한자 글리프가 섞이지 않음을 플랫폼 글꼴로 확인했다.
- 홈/문서 모바일과 데스크톱 캡처, 1440px 화면의200% 확대에 해당하는720 CSSpx 재배치 확인. 실제 브라우저 확대 UI/실기기 검증은 아니다.
- WOFF2 요청을 중단한 새 페이지에서도320px에서 대체 글꼴로 코드 생성/조판을 유지했다. pageerror0건. [실제 글꼴/화면 데이터](../../../assets/typography/result.json).
- 두 OFL 원문은 로컬 HTTP로 제공된 내용이 원본과 동일했다.
- 원본 README 썸네일, 소개 영상과 외부 위젯 번들은 아래 SHA-256이 이전과 동일하다. 원본 Pretendard OFL을 제외한 변경의 `git diff --check`를 통과했다. OFL22행의 공백은 공식 원문 그대로 보존한다.

## 발견한 문제와 조치

첫 전체 회귀는79/79였지만 한국어 브랜드의 한 글자 줄바꿈을 고친 후 영어320px 헤더가89px로 늘어나는 실패가 나타났다. 긴 영어 브랜드3줄에24px 줄 간격이 적용되는 원인이었다. 기존 메뉴 검사가 `document.fonts.ready` 이후 확인하도록 보강해89px 실패를 재현한 뒤, 모바일 브랜드를16px 글자/20px 줄 간격으로 수정했다. 최종 전체79/79로 헤더80px 이하와 Escape 포커스 복귀를 확인했다. 한국어는 keep-all과136px 최대 너비로 어절을 유지한다.

## 후속 PR 준비와 독립 코드 검토

사용자가 “풀리퀘”로 커밋/푸시/PR을 요청했다. 기존 PR #10이 병합된 최신 main `d5635ec`는 구현 기준 커밋과 파일 트리가 동일해 폰트 작업만 feat/village-typography 브랜치로 옮겼다. 단위146/146, 타입/사이트+위젯 빌드, 전체 브라우저79/79(46.6초)를 새로 실행해 통과했다. 위젯/썸네일/영상의 위 해시도 재확인했다.

새 문맥의 `typography_pr_review`가 변경 CSS와 계획/명세, 글꼴/라이선스, 실제 화면/검증 데이터를 독립 검토했다. 수정이 필요한 material finding은 없고 PR 게시 가능으로 판단했다. 검토자는 전체 테스트를 재실행하지 않았으며 root가 위 검사를 수행했다. 실제 티스토리/실기기/보조 기술과 실제 브라우저 확대 UI는 검토 범위 밖이며 전체 EGM 승인으로 기록하지 않는다. 병합과 배포는 수행하지 않는다.
