# 소개 영상 플레이어 독립 코드 검토

검토일: 2026-11-20. 기준 커밋 `a9c5ff5`, `feat/brag-intro` 작업 트리의 변경을 대상으로 했다. 사용자 요청에 따라 Claude Code의 새 세션에서 Read/Glob/Grep만 허용한 읽기 전용 검토를 실행했다. 영상 제작 세션과 다른 문맥이다.

## 범위와 결과

`src/intro-video.ts`, `src/demo.ts`의 영상 마크업/초기화, `src/demo.css`의 영상/모바일 규칙과 `tests/intro.spec.ts`를 VV-010~012 기준으로 확인했다. 확정된 중요 결함은 보고되지 않았다.

- 처음 보이는 영상에만 음소거 자동 재생을 시도하고 기본 컨트롤을 남긴다.
- 화면 밖/숨긴 탭 정책은 한 상태로 결합하고 이전 재생 의도를 보존한다. 사용자가 멈춘 영상은 복귀할 때 재생하지 않는다.
- 비동기 play 거부와 pause에 따른 AbortError를 처리한다.
- 모션 줄이기는 초기 자동 재생을 막지만 사용자의 직접 재생을 허용한다. 재생 중 설정을 켜면 멈추고 재개 의도를 제거한다.
- 파일 오류 시 포스터와 직접 파일 링크가 남고 상태 안내가 표시된다.
- 480px 이하 레이아웃과 동적 마크업의 해시 이동 보완을 확인했다.

## 검증 경계

검토자는 명령이나 테스트를 실행하지 않았다. 구현자가 Chrome에서 4개의 영상 검사와 기존 18개의 위젯 검사 통과를 확인했다. 실제 탭 숨김/재표시와 실행 중 모션 설정 변경은 자동 검사에 별도로 포함하지 않았다. 수동 정지 보존 검사는 HTMLVideoElement.pause()를 통해 상태를 변경한다. 현재 결함이라는 판단은 아니며 회귀 검사 범위를 기록한 것이다.

전체 EGM 반복 수렴이나 실제 티스토리 설치 검증을 완료했다고 주장하지 않는다.
