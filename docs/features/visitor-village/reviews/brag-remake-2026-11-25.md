# Claude Code brag 재제작과 README 정리 검증

사용자가 첨부한 이전 영상 화면을 바탕으로 소개 영상을 Claude Code brag 스킬로 다시 만들고 README의 불필요한 내용을 제거하도록 요청했다. 기존 상단 썸네일과 체험 이미지 버튼은 유지했다. [작업 계획](../brag-remake-plan.md)을 따른다.

## 실제 제작 경로

Claude Code CLI의 실제 Skill 도구 호출 `brag:brag --tone polished --duration 20 --format landscape`를 확인했다. 모델은 claude-opus-5-5, 세션 한정 플러그인은 brag0.6.0(공식 소스06379432)이다. 공식 모델 분기에 따라 번들 brag-slim으로 진행했으므로 이번 제작을 HyperFrames 실행으로 기록하지 않는다. Vite의 실제 Web Component,Playwright/Chrome과FFmpeg를 사용했다. 전역 플러그인 설정이나 제품 실행 코드는 바꾸지 않았다.

6장면은 방문 수 증가,인사 근접 장면,루돌프,계절 변화,설치와 마무리다. 고정 시드/모델 시간으로 실제 원화를 캡처했고 시연 인원과 카메오 등장 시점을 연출했다. 긴 하단 문구를 반복하지 않고 훅의 시연 배지와 마지막의 짧은 문구로 구분했다. 음원은 기존 Sascha Ende CC BY4.0 음악과 CC0효과음을 사용했다. 내레이션과 새 유료 서비스/의존성은 없다.

[편집 원본과 기획](../../../../assets/concepts/brag-remake/README.md)을 보존했다. 원시 CLI로그와 큰 프레임/음원/글꼴은 ignored 작업 폴더에 있으며,공개 문서에는 인증/사용자환경 메타데이터를 복사하지 않았다.

## README 정리

한국어253줄,영어/일본어/중국어237줄을 각각44줄로 줄였다. 썸네일/소개/체험 버튼/영상/핵심기능/설치/짧은 개발 명령만 남겼다. 중복 배포 안내,작은 스프라이트 규격,긴 API표/저장소 구조와 README 구성 참고는 본문에서 덜어냈다. 유용한 수동 설치 코드/속성/API/이벤트/개발/음원 출처는 docs/reference/widget.*.md에 보존했다. 네 언어의 설치 코드와 공개API 보존을 대조했고 링크10개 문서의 상대 경로가 유효했다. 원래 썸네일과 이미지 CTA도 바이트 단위로 동일하다.
