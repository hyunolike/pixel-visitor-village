# 홈·설치·사용 문서 개편 검토와 검증

기준: HEAD 0fcdb54, feat/visitor-notice. 사용자가 레퍼런스 분석 뒤 3페이지 구성의 실행을 승인했다. 기존 디자인 시스템과 공개 배포 상태를 확인한 뒤 같은 깨끗한 작업 공간에서 진행했다. 이번 변경의 커밋/푸시/공개 배포는 수행하지 않았다.

## 실제 독립 검토

- 첫 site_pages_readiness 실행은 파일을 읽기 전에 중단되어 준비 완료로 기록하지 않았다. 같은 새 문맥 검토자에게 계획 한 파일만 읽도록 재요청했다. 실제 site-pages-plan.md 내부 검토에서는 명백한 Blocker/Major 없음으로 보고했다. 소스/테스트와의 일치까지 검토한 것은 아니다.
- site_pages_code_review는 이번 diff와 신규 문서/스타일/계획 및 새 테스트를 읽고 Critical/Important 없음으로 보고했다. 정적 문서 본문과 CSS 상대 경로/빌드 진입점, #demo/#intro-film, 링크 중첩 없음, 5개 속성/기본값과 한국어 문서 표시를 확인했다. 실행과 실제 배포는 검토 범위가 아니다.
- Minor는 새 320px 검사에 설치 4개 언어 헤더의 개별 링크/선택기 경계 검사가 빠졌다는 점이었다. 언어 전환마다 모든 메뉴와 선택기의 bounding box, 전체 scrollWidth, 생성 코드 보존을 실제 Chrome으로 검사하도록 보완했다. 메뉴는 기존 caption 14px를 유지하고 새 탭 안내도 4개 언어로 번역했다.
