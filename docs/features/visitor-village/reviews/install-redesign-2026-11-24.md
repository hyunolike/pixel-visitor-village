# 설치 페이지 개편과 다국어 검증

## 승인과 범위

사용자는 외부 레퍼런스 기반 디자인 시스템과 설치 페이지 개편, 다국어 처리를 요청하고 시각 보드와 네 언어 지원을 확인한 뒤 “진행해줘”로 구현을 승인했다. 설치 페이지만 개편했고 기존 작업 트리의 방문 수 팻말, 선택 조회와 크리스마스 장식 변경을 보존했다. 커밋, 푸시, 공개 배포와 실제 티스토리 스킨 쓰기는 하지 않았다.

## 실제 독립 검토

- 사전 builder check: `install_design_check`, fresh context, 중요한 미정 질문 없음. 당시 원본 결과는 `install-design-builder-2026-11-24.md`에 있다.
- 구현 준비 검토: `install_readiness`, fresh context, EGM implementation_readiness 지침과 implementation-readiness-standard를 읽은 뒤 계획/설계/소스를 확인했다. 오류 code 계약과 표시 중인 팻말의 재번역 규칙 두 Major를 지적했고 계획에 명시했다. 전체 EGM 5단계를 완료했다고 주장하지 않는다.
- 최종 코드 검토: `install_code_review`, fresh context, 읽기 전용. 실행 계획, VV-INSTALL-001~004와 설치/번역/위젯 통합 소스를 실제로 읽고 Important 1건과 Minor 1건을 반환했다. 테스트를 직접 재실행하지 않았으며 작성자의 자체 검토로 대체하지 않았다.

### 검토 지적과 조치

1. Important: 위젯이 번역한 canvas aria-label을 렌더러가 다음 프레임에 한국어로 덮어썼다. 모션 reduce/no-preference 두 브라우저 검사에서 실제 한국어 수신을 확인한 뒤, 렌더러에 VillageLabels를 전달해 계절/방문 수/장식 설명을 매 프레임 같은 언어로 구성하도록 수정했다. 두 회귀 모두 통과. 기본 독립 위젯의 한국어 설명은 유지했다.
2. Minor로 보고된 언어 태그 처리: en--GB/ja-!도 기본 언어로 허용돼 저장된 선택을 무시했다. VV-INSTALL-004의 잘못된 언어 대체 계약에 해당해 수정 범위에 포함했다. 단위 검사 3개 실패를 확인한 뒤 전체 태그를 Intl.getCanonicalLocales로 검증하도록 수정했다. 지역 변형은 계속 정규화하며 전체 단위 검사 통과.

검토에서 제외한 것은 메인 데모 전체 번역, 공개 배포와 실제 티스토리 스킨 적용, 별도 작업인 방문 수 알림과 크리스마스 장식의 내부 동작이다. 이 범위는 확대하지 않았다. 중요 수정 후 별도 재검토를 실행한 것으로 기록하지 않으며 회귀 검사로 검증했다. 보류한 지적 없음.

## 검증 결과

- 시작 시 기존 단위 81개 통과. 같은 작업 트리의 다른 기능 추가를 포함한 최종 `pnpm test`: 6파일, 110/110 통과.
- `pnpm typecheck`: 통과. `pnpm build`: TypeScript, 사이트와 독립 위젯 빌드 통과. 새 런타임 의존성 없음.
- 설치 전용 검사: 언어 선택, 네 언어의 320px 화면/오류/코드 생성, 복사/언어 전환 상태 보존, 저장소 차단, 클립보드 실패/늦은 완료, 미리보기 그래픽 실패/재시도, 다섯 계절, ID/위치 보존, 모션 줄이기와 키보드를 확인했다.
- 최종 전체 브라우저 검사: `pnpm test:e2e --config=/private/tmp/pvv-install-check.config.ts`, 52/52 통과. 설치 관련 16개 외에도 기본 위젯, 외부 출처 로드, 영상, 팻말/조회와 크리스마스 장식 회귀를 포함한다.
- 표준 포트 4178에서 다른 세션의 미리보기 서버가 사용 중이라 임시 설정으로 4191에서 같은 Chrome/전체 tests 디렉터리를 검증했다. 저장소의 브라우저 설정은 바꾸지 않았다. 검사 내 출처는 고정 포트 대신 configured baseURL을 사용하도록 정리했다.
- 전체 첫 실행에서 크리스마스 장식의 화면 복귀/가짜 시계 검사가 실패했고 단독 재실행은 통과했다. 화면 복귀를 toBeInViewport로 확인한 뒤 가짜 시계를 진행하도록 동기화했다. 제품 동작을 바꾸지 않았고 최종 전체 검사도 통과했다.
- `git diff --check`: 통과.

### 시각과 접근성

실제 로컬 배포 번들의 1440px 한국어와 390px 영어 화면을 캡처하고 확인했다. 네 언어 320px 화면도 가로 넘침이 없었다. 설치 코드는 티스토리 치환자와 현재 origin을 보존하며 기본 조회는 꺼짐이다. 미리보기 숫자 24는 시연용이다.

색상 계산 결과: 본문/페이지 14.04:1, 보조문/흰 배경 5.67:1, 주 버튼 흰 글자 5.98:1, 선택 상태 5.09:1, 입력 경계/흰 배경 3.43:1, 오류 6.49:1, 성공 7.16:1. 자동화로 대비와 키보드를 확인했으며 스크린 리더 실기기 감사를 수행한 것으로 설명하지 않는다.

캡처는 `docs/assets/install-desktop.png`, `docs/assets/install-mobile.png`다. 기존 마을 아트의 실제 렌더이며 제안 도식인 install-redesign-proposal.png와 구분한다. 실제 티스토리 집계, 스킨 설치, Safari/iOS 실기기와 운영 배포는 이번 검증이 아니다.
