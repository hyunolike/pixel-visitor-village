# 자동 인사 구현 검토와 검증

날짜: 2026-11-25. 사용자 승인 범위는 자동 인사/아이콘 반응 구현과 주변 집/나무 레퍼런스 조사다. 기존 미커밋 위젯/설치 변경을 보존했다. 커밋/푸시/공개 배포는 수행하지 않았다.

## 실제 독립 사전 검토

새 문맥 social_spec_review가 EGM implementation-readiness 기준으로 전체 계획과 관련 구현을 읽었다. Blocker는 없었고 Major 세 건을 제시했다. 취소/ID 재사용/재연결의 수명, 리사이즈 후 쌍 유지 기준, 접근성 설명/브라우저 관찰 계약이 모호했다. social-plan.md에 사건별 상태 표, 소유자 해제 위치, 생성 시 거리 적용과 오래된 쌍 우선 유지, 실제 단계와 쌍 수에 따른 네 언어 설명을 추가했다.

## 실제 독립 코드 검토

별도 새 문맥 social_code_review가 이번 코드와 시작 시점 사본(/tmp/visitor-social-baseline)을 비교했다. reduced-motion=true에서 연결 해제 후 분리 중 모션 설정을 해제해 재연결하면 모델이 계속 비활성인 Important 문제를 찾았다. 새 renderer의 기본값과 모델의 보존된 enabled가 달랐기 때문이다. 브라우저 회귀를 먼저 추가해 기존 번들에서 인사 없음으로 실패를 재현한 뒤 setMotionReduced가 모델 상태를 항상 동기화하게 수정했다. 검토자가 수정과 정확한 회귀 경로, 손 그림의 내려온 오른손 배제도 재확인했으며 추가 Critical/Important 문제는 없다고 최종 보고했다.

## 검증 증거

- 신규 순수 상태/그림/포즈 테스트는 모듈/함수 부재로, 모델 연결 테스트는 setViewport 부재로 먼저 실패한 뒤 구현했다. 기존 번들의 새 브라우저 테스트 세 건도 인사 설명 부재로 실패했다.
- pnpm test: 128/128 통과. 거리/중복/세 단계 수명/휴식/ID 재사용/중앙 줄기/리사이즈/비활성/5,000명 밀집 검색 예산/말풍선 경계와 실제 픽셀 차이를 검사했다. 손을 올린 상태에 내려온 손이 남는 문제도 픽셀 alpha 실패를 먼저 확인한 뒤 수정했다.
- pnpm build: 타입 검사와 앱/독립 위젯 빌드 통과.
- pnpm test:e2e --config /tmp/visitor-social-check/playwright.config.ts: 고정한 빌드의 Chrome 전체 56/56 통과. 공유 dist/포트의 동시 작업 간섭을 피하려 빌드를 별도 위치에 복사하고 origin만 5200으로 맞췄다.
- 정지/재개, 인사→말풍선, count 감소/재생성, 재연결, 모션 설정 변경, 320px 한 쌍, 설치 미리보기 네 언어를 검사했다. 정지 중 장면의 픽셀 비교에서는 별도 알림 시계로 사라지는 나무 팻말만 숨겨 장면 자체를 비교했다.
- [데스크톱](../../../assets/social-desktop.png), [320px](../../../assets/social-mobile.png)의 실제 Pixi 캡처를 직접 확인했다. 말풍선 표시와 화면 경계, 기존 계절/캐릭터 표현을 확인했다.
- 기본 시연 24명도 별도 Chrome 확인에서 데스크톱 3쌍, 320px 1쌍 인사가 발생하고 실제 count는 24로 유지되는 것을 확인했다.
- 네 언어 README의 상대 링크/에셋 207개와 제목 앵커 36개, 언어 이동, 동일 삽입 코드/기술 계약 확인 통과. git diff --check 통과.

## 조사와 검증 경계

design.md의 주변 환경 조사에 SLYNYRD 원작자 튜토리얼 두 건, Kenney Tiny Town, Cup Nooble Sprout Lands와 이용 조건을 기록했다. 튜토리얼의 잎 클러스터 그림도 직접 확인했다. 주변 환경 아트는 교체하지 않았다. 외부 에셋을 프로젝트에 추가하거나 새 의존성을 설치하지 않았다.

상호작용은 실제 방문자의 메시지/이름/방문 시각/지역과 무관한 장식이다. 실제 방문 데이터 수집 서버는 구현하지 않았다. 검증은 로컬 Chrome과 고정 배포 번들 기준이며 설치된 티스토리 블로그의 반영과 모바일 실기기 확인은 포함하지 않는다.
