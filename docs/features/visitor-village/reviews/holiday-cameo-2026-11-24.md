# 직각 프레임과 크리스마스 손님 검토

## 범위와 실제 독립 검토

feat/visitor-notice의 기존 미커밋 팻말 작업 위에서 VV-022~024만 검토했다. 시작 내용은 /tmp/visitor-holiday-baseline에 따로 보관했고 기존 설치 페이지 다국어 작업을 덮어쓰지 않았다.

새 문맥의 holiday_review가 코드 검토 지침과 EGM implementation_readiness persona, 실행 계획, 해당 명세, 새 모델/그림, renderer, 컴포넌트 연동, 모델/픽셀 테스트, 새 브라우저 검사와 CSS 차이를 실제로 읽었다. Pixi의 ticker, Sprite, Texture와 Application 정리 구현도 읽었다. 직접 서버/브라우저/빌드를 실행하거나 파일을 수정하지 않았다.

- Critical/Important: 없음. 정적 검토 기준 준비됨.
- Minor: 수동 정지 중 게스트 보존과 재개, 같은 계절의 크기/수 변경 보존을 브라우저에서 더 확인할 것. 독립된 두 모델을 비교하는 단위 검사보다 렌더러에서 방문자 상태를 확인할 것.
- 조치: 기존 게스트 수명 검사에 긴 수동 정지, count 24→37, 320px 리사이즈 중 게스트 보존과 기존 방문자 좌표 보존, 재개 후 퇴장 검사를 추가했다.
- 제외: 기존 팻말/주기 조회와 설치 페이지의 별도 다국어 변경, 실제 티스토리 집계, 운영 배포.

## 검증 경로

1. 모델/그림 모듈이 없는 상태에서 새 단위 검사의 실패를 확인했다.
2. 기존 번들에서 border-radius=12px와 산타/루돌프 없음으로 새 브라우저 4개가 실패하는 것을 확인했다.
3. 구현 후 해당 4개가 통과했고 산타/루돌프의 실제 데스크톱 그림을 확인했다.
4. 320px 화면에서도 두 출현/퇴장 검사가 통과했으며 해당 캡처를 남겼다.
5. 전체 검사 중 화면 밖→복귀의 가시성 콜백보다 가상 시간이 먼저 진행하는 테스트 경합을 발견했다. 고정 100ms 대기 대신 실제 viewport 진입/이탈과 Canvas 리사이즈 완료 조건을 기다리도록 수정했다.
6. 공유 dist와 포트에 다른 작업의 빌드/검증이 함께 진행돼 최종 전체 검사는 별도 고정 빌드/출력/포트에서 수행한다. 테스트 복사본의 변경은 localhost 4178→5199뿐이며 assertion은 그대로다. 테스트 소스/설정의 원본을 이 목적으로 변경하지 않았다.
