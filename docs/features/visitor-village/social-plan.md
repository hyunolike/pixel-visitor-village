# 캐릭터 자동 인사와 아이콘 말풍선 구현 계획

사용자가 상호작용 조사 뒤 진행을 승인했다. 실행은 현재 세션에서 직접 하고 새 문맥의 사전/코드 검토를 받는다. 기존 위젯/설치/크리스마스 변경은 보존하고 커밋/푸시/공개 배포는 하지 않는다.

**목표:** 가까운 두 캐릭터가 잠깐 멈춰 서로 보고 손을 흔든 뒤 작은 아이콘 말풍선으로 반응하고 각자 걷기로 복귀한다.
**구조:** 순수 SocialModel과 공간 격자 검색을 VillageModel의 기존 활성 시간에 연결한다. 기존 Pixi 아틀라스에 두 손 동작을 추가하고 말풍선은 공유 아틀라스/최대 3개 Sprite를 재사용한다.
**명세:** spec.md VV-025~027, design.md의 캐릭터 상호작용 조사와 이번 확정 범위.
**기준:** feat/visitor-notice, HEAD 24010fc와 기존 미커밋 작업. 이번 대상 시작 내용은 /tmp/visitor-social-baseline에 보관했다.

## 확정한 계약

- 첫 후보 확인은 활성 시간 2초 뒤, 이후 0.4초 간격이다. 인사는 1.2초, 반응은 1.8초, 총 3초다. 각 참여자는 종료/취소 뒤 18초 쉰다.
- 뷰 너비가 내부 좌표 220px 미만이면 한 쌍, 그 외 최대 세 쌍이다. 같은 캐릭터는 한 쌍에만 속한다. 마지막 참여자 수를 줄이지 않으며 count와 실제 방문자 ID/공개 스냅샷 형식은 유지한다.
- 월드 좌표 거리 22~42px, 세로 차 14px 이하인 후보만 선택한다. 중앙 줄기 사각형을 가로지르는 쌍은 제외한다. 후보 격자는 42px이며 한 셀의 후보 저장을 16명, 한 확인의 후보 비교를 최대 512회로 제한해 밀집 5,000명도 전수 쌍 비교를 하지 않는다.
- 기존 방문자 위치를 재배치하지 않는다. 참가자는 기존 걷기 계산을 잠시 건너뛰고 상대를 바라본다. 두 손 동작 프레임으로 인사하고 반응 중에는 서 있다.
- 반응 아이콘은 점 세 개/하트/반짝임 중 하나다. 한 쌍의 두 캐릭터가 절반 시간씩 번갈아 머리 위에 표시하므로 한 쌍당 동시에 하나다. 실제 채팅/이름/방문 시각/지역을 표시하지 않는다.
- 작은 화면의 말풍선 전체가 뷰 안에 있도록 위치와 스케일을 제한한다. 각 Sprite의 발 기준 깊이 정렬을 유지한다.
- count 감소/0, 계절 변경, 연결 해제 시 사라진 참가자의 쌍을 해제하고 남은 참가자도 정상 걷기로 돌린다. 정상 count 증가와 같은 계절 리사이즈는 가능한 쌍을 유지한다. 작은 화면으로 바뀌어 쌍 한도를 넘으면 초과 쌍만 해제한다.
- 수동 정지/탭 숨김/화면 밖에서는 기존 ticker와 함께 진행/휴식 시간이 멈춘다. 모션 줄이기를 켜면 상호작용을 해제하고 새 쌍을 만들지 않는다. 다시 켜면 2초 대기부터 시작한다.
- 기존 전체 마을의 GitHub 링크를 유지한다. 클릭 상호작용/동행/선물 전달/LLM/별도 수집 서버와 주변 환경 그림 교체는 이번 구현에 포함하지 않는다. 주변 집/나무는 레퍼런스 조사와 개선안까지만 작성한다.

## 파일과 인터페이스

사전 독립 검토의 Major 세 건은 다음 계약으로 해소한다.

| 사건 | 쌍 / 휴식 / 다음 검색 |
|---|---|
| 정상 종료, 실제 계절 변경, 모션 줄이기, 연결 해제 | 참여 쌍 해제, 남아 있는 ID의 18초 휴식 유지. reset/재활성 뒤 최소 2초 대기 |
| count 감소 | 사라진 참가자가 속한 쌍 해제. 남은 참가자는 휴식, 삭제된 ID의 휴식은 삭제 |
| count 증가 / 삭제된 ID 재사용 | 기존 쌍 유지. 새 ID는 이전 수명의 휴식을 상속하지 않음 |
| viewport 변경 | 거리 조건은 생성 시에만 적용. 기존 쌍을 유지하며 한도 감소 시 가장 최근 생성한 쌍부터 취소하고 휴식 적용 |
| 수동 정지 / 숨김 / 화면 밖 | 쌍, 단계, 휴식, 검색 시계 모두 정지 |

연결 해제 초기화는 소유자인 VisitorVillage.disconnectedCallback에서 model.social.reset()으로 수행한다. Renderer.destroy()는 모델을 변경하지 않으므로 오래된 비동기 렌더러 정리가 새 연결의 상태를 지우지 않는다. 모션 줄이기로 멈춘 동안 휴식 시계도 멈추고 해제 뒤 남은 휴식을 진행한다.

canvas 접근성 설명은 실제 쌍이 있을 때만 현재 쌍 수와 단계(손 인사/말풍선 반응)를 네 언어로 덧붙인다. 평상시 문자열은 유지하고 취소/모션 줄이기 시 즉시 제거한다. 브라우저에서는 단계 설명, 고정 시계 동안 캔버스 스크린샷 동일성, 재개 후 단계 종료, 말풍선 단계의 실제 장면 스크린샷을 함께 확인한다. 삭제 후 ID 재사용과 연결 해제→재연결도 검증한다.

- src/social.ts(신규): SocialModel(random?:()=>number), step(people,seconds), reconcile(people), reset(), setViewport(width,height), setEnabled(boolean), pairs 읽기 전용 목록과 getPartner(id). Pair는 firstId/secondId/age/emote를 가진다.
- src/model.ts: social 소유, viewport 전달, 유효 입력 이후 reconcile, 실제 계절 변경 시 reset, tick에서 소셜 진행 뒤 참가자 이동 건너뛰기.
- src/character-motion.ts: interactionPose(dx,dy,age,result?)로 상대 방향과 인사 6/7 또는 서기 0 선택.
- src/characters.ts: 기존 0~5 프레임 유지, 6/7 손 흔들기. 프레임 수 상수 8로 렌더러와 공유.
- src/social-art.ts(신규): 18×14 RGBA 아이콘 말풍선 3종과 getBubbleLayout. 외부 에셋 없이 DOM/GPU와 독립 검사.
- src/renderer.ts: viewport→모델 전달, 손 동작 아틀라스 확장, 참가자 pose 적용, 말풍선 3개 풀과 공유 소스 생성/정리, reduced-motion 연동.
- src/village-labels.ts, src/install-i18n.ts: 장면의 상호작용 설명을 한국어/영어/일본어/중국어로 표시. 기존 계약 유지.
- 테스트: src/model.test.ts, src/character-motion.test.ts, src/characters.test.ts, tests/widget.spec.ts.
- 문서: 기존 spec/design/tasks, 네 언어 README, reviews/social-2026-11-25.md, design.md의 주변 환경 조사 절.

## 검토 초점

사라진 참가자/ID 재사용, 한 프레임 안의 해제와 재예약, 같은 계절 리사이즈의 쌍 유지, 비활성 중 타이머 진행, 많은 인원이 같은 셀에 모일 때 검색 상한, 다른 언어의 장면에 한국어가 섞이지 않는지 확인한다.
