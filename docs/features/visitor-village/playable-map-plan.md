## Architecture and exact boundary

Existing Vite multipage service and real Web Component remain. No new router or runtime dependency. Assets: src/assets/map/landscape-{spring,summer,autumn,winter,christmas}.webp and guide.png; original sources/provenance in assets/concepts/map-20261126. Reuse actual sprite data for a guide portrait through a repository-native export script if needed, without external characters.

Widget bridge: VisitorVillage.setSceneBackdrop(source:HTMLImageElement|null):void stores a loaded source per instance, calls VillageRenderer.setSceneBackdrop(source) when ready, reapplies on reconnect and does not change counts/attributes. The renderer owns any created texture and destroys it on resize/replacement/disconnect. setTheme still builds real scenery; only the terrain bitmap and map tree/well positioning are changed when an optional source is present. Null restores the exact default. No network fetch inside the renderer or model.

Service helper src/map-scene.ts owns a Season→URL map and cached source-image promises; it loads only the chosen season, clears the old map presentation while waiting, and ignores completions for obsolete seasons or detached widgets. A failed promise is evicted so a later selection can retry; current fallback stays usable and a nonblocking data state records loading/ready/fallback. This helper serves home and the install preview. ResizeObserver places home signs using actual half-resolution scene dimensions and getVillageLayout, with mobile clamps. Independent instances own textures although source-image promises can be cached.

Source writes: src/{demo.ts,demo.css,design-system.css,service-chrome.css,site-pages.css,install.css,install.ts,install-i18n.ts,docs.ts,docs.css,renderer.ts,visitor-village.ts,map-scene.ts}; docs/index.html; install.html; tests/widget.spec.ts; new src/map-scene.test.ts only if a pure new transform warrants it; scripts/media/export-guide.mjs and artwork provenance if needed; existing feature spec/design/tasks, this plan, design-qa.md, reviews/playable-map-2026-11-26.md and docs/assets/playable-map/*.png. Do not rewrite model, media, README thumbnail, deployment secrets or CI. Dev formatter script may add the new map-scene/docs files to its explicit list. Existing exact-copy/style tests may migrate assertions only where the selected visual intentionally replaces them; preserve their behavioral guarantees.

Helper API setupMapScene(widget:VisitorVillage):()=>void registers both village-change and village-ready.
