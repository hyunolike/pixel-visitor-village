# 서비스 타이포그래피 적용 계획

**Goal:** 픽셀 마을의 제목과 브랜드에 개성을 주고 설치 안내의 가독성을 유지한다.
**Architecture:** 사이트 공통 CSS의 글꼴 역할을 display/body로 나누고 원본 WOFF2를 자체 제공한다. 위젯 Shadow DOM과 캔버스, README 썸네일, 영상은 변경하지 않는다.
**Tech Stack:** 기존 CSS/Vite/Playwright. 의존성 추가 없음.
**Spec:** spec.md의 VV-TYPE-001~003, design.md의 서비스 타이포그래피.

사용자가 디자인 시스템 후속 요청으로 “폰트도 변경해줘 서비스에 맞게”라고 명시했다. 폰트 변경은 현재 화면에 적용하며 앞선 레이아웃 3안은 선택되지 않았다. 기존 linked worktree에서 구현과 검증을 완료한 뒤, 후속 “풀리퀘” 요청에 따라 최신 main의 feat/village-typography 브랜치에 커밋/푸시하고 PR을 만든다. 병합과 공개 배포는 이번 요청에 포함하지 않는다.

## 적용과 검증

- [x] 공식 Neo둥근모 v1.600과 Pretendard v1.3.9 원본 WOFF2 및 OFL 전문을 확보하고 출처/해시를 기록한다.
- [x] Neo둥근모는 한국어/영어 브랜드 16px, 큰 제목 32/48px, 시연 수 32px에만 적용한다. 합성 굵기와 음수 자간을 쓰지 않는다. 섹션 제목/본문/입력/버튼은 Pretendard다. 일본어/중국어는 해당 언어 시스템 글꼴을 일관되게 사용한다.
- [x] font-display:swap과 시스템 대체 글꼴로 실패 시 내용을 보존하고 코드는 고정폭을 유지한다.
- [x] 타입/사이트+독립 위젯 빌드, 전체 브라우저 회귀, 실제 글꼴 로딩/375px와 데스크톱/네 언어/폰트 실패/200% 상당720 CSSpx 재배치를 확인했다. 위젯 번들 해시와 썸네일 바이트가 이전과 동일하다.
- [x] [실제 화면과 결과](reviews/typography-2026-11-25.md)를 기록했다. 자체 검증을 독립 EGM 검토로 표현하지 않는다.
