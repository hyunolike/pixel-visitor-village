## 전달 상태와 다음 시작점

소스와 의존성 잠금 파일, 문서와 빌드 산출물을 프로젝트 폴더에 반영한다. 이번 기능 변경은 커밋과 푸시를 하지 않는다. 공개 호스팅은 후속 Vercel 배포 단계에서 완료했다.

다음은 위젯 모듈 호스팅 주소를 정하고 대상 티스토리 스킨에 삽입하는 작업이다. 계정과 스킨 접근이 없어 이 단계를 완료했다고 기록하지 않는다. 합성 크리스마스 PNG의 장식별 분리는 후속 선택사항이다. 저사양 기기의 목표 프레임률은 아직 정하지 않았다.

- [x] 승인된 Vercel production에 공개 배포, 실제 CORS/비로그인 접근과 공개 코드의 교차 출처 로드 검증.
- [ ] 실제 티스토리 스킨에 삽입해 오늘 방문자 수와 일치 확인.

Vercel 공개 배포를 완료했다. 실제 블로그 스킨 편집은 실행하지 않았다. 커밋과 푸시는 별도 요청이 없어 보류한다.

## 설치 도우미 검증

주소 정규화와 코드 생성 단위 테스트 12개를 추가해 전체 40개가 통과했다. 교차 출처 삽입과 설치 코드 생성/복사를 포함한 브라우저 시나리오는 전체 18개가 통과했다. 최초 교차 출처 테스트는 모의 내비게이션의 loopback 주소 공간 차단으로 실패했으며, 실제 별도 HTTP 서버 출처로 바꿔 네트워크 동작을 검증했다.

## 전달할 공개 결과

https://pixel-visitor-village.vercel.app/install.html 에서 블로그 주소를 입력하고 코드를 복사한다. 소유자가 최초 한 번 스킨에 붙여 넣어야 한다. 단위 테스트 40개, 브라우저 테스트 18개와 실제 production 공개 설치/교차 출처 smoke test 1개를 통과했다. 현재 남은 외부 확인은 사용자의 실제 스킨 적용이다.
