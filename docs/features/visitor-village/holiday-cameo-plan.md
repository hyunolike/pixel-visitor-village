# 직각 프레임과 크리스마스 손님 구현 계획

사용자 요청: 마을의 둥근 모서리를 직각으로 바꾸고 산타와 루돌프가 무작위로 나타났다 사라지게 한다. 이 요청의 구현/검증 범위에서 직접 진행하며 커밋/푸시/공개 배포는 포함하지 않는다.

- 별도 설치 페이지 디자인/다국어 작업은 범위 밖이다. 그 변경과 파일은 보존한다.
- 변경 파일: src/widget.css, src/demo.css, src/holiday-cameo.ts(신규), src/holiday-art.ts(신규), src/renderer.ts, src/visitor-village.ts, src/model.test.ts, src/characters.test.ts, tests/widget.spec.ts, 네 언어 README, docs/features/visitor-village/{spec,design,tasks}.md, reviews/holiday-cameo-2026-11-24.md.

## 확정한 동작

- 위젯 외곽/계절 이름/오류 안내/저장소 링크와 데모의 카드/입력/버튼/영상 모서리는 border-radius:0으로 바꾼다. 그림 속 나무/집/캐릭터 형태와 별도 설치 페이지의 디자인은 유지한다.
- 크리스마스에서 산타/루돌프 중 하나를 같은 확률로 선택한다. 동시에 최대 한 명, 첫 등장은 활성 시간 4~8초 뒤, 한 번에 5~8초 머물고 다음까지 20~40초 쉰다.
- 두 그림은 원본 32×36px, 2개 자세의 자체 RGBA 픽셀 데이터다. 산타는 수염/모자/붉은 옷, 루돌프는 뿔/붉은 코/네 다리로 구분한다. 한 아틀라스/스프라이트를 재사용하며 등장마다 에셋/타이머/텍스처를 만들지 않는다.
- 광장 좌/우의 정해진 범위에서 위치를 무작위로 고르고 나무/집/방문자와 같은 발 기준 깊이 정렬을 쓴다. 뷰 크기에 맞춰 축소해 1px/작은 높이에도 좌표와 스케일이 유효하다.
- 출현/퇴장은 약 0.3초 투명도로 부드럽게 연결한다. 해당 손님은 실제 방문자가 아니며 count, 방문자 ID/위치, 공개 이벤트의 count를 바꾸지 않는다.
- 숨긴 탭/화면 밖/수동 정지에서는 기존 renderer ticker와 함께 출현/퇴장 시계도 멈춘다. 긴 프레임 공백은 최대 .05초로 제한한다.
- 모션 줄이기 설정에서는 손님 연출을 끄고 즉시 숨긴다. 크리스마스 밖으로 바꾸면 즉시 숨기고, 되돌아오면 첫 대기 시간부터 다시 시작한다. 같은 테마의 리사이즈/count 변경은 진행을 초기화하지 않는다.
- Canvas의 장면 설명에는 보이는 크리스마스 손님 이름을 넣되 live 알림을 추가하지 않는다. 위젯 전체의 저장소 링크와 모바일 스크롤을 유지한다.

## 완료 기록

단위 110/110, 타입 검사와 사이트/독립 번들 빌드, 고정 빌드의 전체 Chrome 검사 52/52, 320px 손님 출현/퇴장 2/2를 통과했다. [독립 검토 기록](reviews/holiday-cameo-2026-11-24.md)에 실제 범위와 지적/조치를 기록했다. 원본 전체 브라우저 실행의 가시성 경합은 조건 대기로 수정했고 공유 빌드 간섭은 별도 출력/포트에서 최종 확인했다. 별도 재검토나 운영 배포로 주장하지 않는다.

이후 요청한 캐릭터 이름표/실제 방문 데이터 수집은 구현하지 않았다. 사용자는 이름표를 보류하고 상호작용 레퍼런스 조사를 기존 작업 완료 뒤 진행하도록 요청했다.
