# 최신 코드 소개 영상과 로고 구조도

사용자가 기존 소개 영상을 최신 코드로 수정하고 동작 구조를 로고가 들어간 직접 그린 이미지로 추가하도록 요청했다. 기준 HEAD2a237d4. 기존20초/1920×1080/30fps와 한국어 안내, 음소거 플레이어/README GIF를 유지한다. 새 커밋/푸시/배포는 이번 요청에 포함하지 않는다.

## 산출물과 계약

- public/media/intro.mp4, intro-poster.jpg, docs/assets/intro-preview.gif를 갱신한다. 영상은 현재 빌드의 실제 visitor-village와 마을 작업실 화면을 캡처한 자료를 HyperFrames로 편집한다. 이전 Canvas2D 재현기나 오래된 Vercel 주소를 재사용하지 않는다.
- 0~8초: 현재 위젯에서 시연0→24명, 실제 인사/아이콘 반응/크리스마스 손님. 8~14초: 봄/여름/가을/겨울 각1.5초. 14~18초: 최신 실제 설치 작업실에서 주소/계절/코드 생성. 18~20초: 프로젝트 로고와 Pages 주소/시연 안내.
- 브라우저 캡처는 시연 입력과 고정 프레임 진행을 사용하고 실제 생산 모델/렌더러/위젯 코드를 수정하지 않는다. 방문자 이름/지역/개별 시각을 연출하지 않는다. 인사/계절/코드 생성은 source에서 실제 지원하는 행동만 보여 준다.
- 음악은 기존 같은 프로젝트의 Sascha Ende CC BY4.0 원본 트랙을 재편집한다. 새 음성/유료 미디어/API는 사용하지 않는다. 로컬 편집 자료는 기존 제외 경로 brag-output/intro-refresh에 둔다. 재생성 스크립트와 출처/렌더 조건은 저장소에 남긴다.
- 동작 구조는 scripts/media의 코드로 SVG를 직접 배치하고 PNG를 함께 출력한다. 한국어/영어 두 버전을 만든다. 티스토리→count→WebComponent→VillageModel/SocialModel→PixiJS→ShadowDOM Canvas, Cloudflare→ES모듈→WebComponent, 자체 그림→PixiJS를 구분한다. 선택적 HTML조회는 기본 꺼짐/60~3600초의 별도 점선으로 표시한다.
- 로고는 티스토리/TypeScript/PixiJS/Cloudflare 공식 파일과 프로젝트의 실제 픽셀 나무 표장을 사용하고 출처를 기록한다. Graph의 화살표/텍스트/그림은 새로 직접 구성한다. 로고를 저장소가 제작한 것으로 설명하지 않는다.
- README는 네 언어에 새 그림을 연결하고 기존 Mermaid는 접힌 텍스트 설명으로 보존한다. 영상이 예전 환경 버전이라는 설명과 과거 제작 과정은 현재 제작 기록/과거 이력으로 구분한다. 실제 티스토리 설치/집계 검증을 주장하지 않는다.

## 검증

1. 영상과 그림의 코드/데이터 흐름·자산 역할에 대한 새 문맥의 최소 준비 검토 후 제작한다.
2. 고정 빌드와 캡처의 source hash, count/season/실제 말풍선/손님, 설치 코드 치환자와 Pages URL을 검사한다.
3. HyperFrames check와 샘플 장면/전환 캡처를 확인한다. 유효한 로컬 preview와 최종20초/600frame H264/AAC, 포스터/GIF 크기·첫 프레임·음량 메타데이터를 검사한다. 오디오는 수치로 측정하며 청취한 것으로 기록하지 않는다.
4. 구조도 SVG/PNG와 로고를 직접 열어 레이블/화살표/겹침/깊은 링크를 확인한다. 독립 검토는 구조와 최종 장면의 P0/P1에 한정한다.
5. README 링크/앵커/기술 코드 보존, pnpm test/typecheck/build/test:e2e와 실제 재생/모션 줄이기/영상 실패 회귀를 확인하고 실제 실행 결과를 기록한다.
